# 数据转换执行系统

纯 Python 标准库实现。转换计划保存在 `plans/`，运行实例保存在 `runs/`，成功结果发布到不可变的 `releases/<plan>/v<version>/`，三者分离。

## 处理流程

计划由有序阶段组成，首批内置算子覆盖：

- `filter`：按安全表达式筛选记录。
- `derive`：用安全表达式派生字段。
- `join`：按一个或多个字段做 inner/left join，保留重复键的所有匹配。

记录使用 JSONL。算子消费命名输入并产生命名输出；后续新增算子只要注册到 `OPERATORS` 并遵循相同的批次、临时目录、JSONL 输出约定，即可复用运行实例、清理和发布机制。

## 内存与发布

- 普通算子按内存预算切分输入批次。
- Join 在预算不足时递归哈希分盘；重复键仍集中在同一桶。
- 极端重复键分桶无法缩小时，退化为外存嵌套循环，避免丢失笛卡尔匹配。
- 失败或取消会删除本次 `runs/<run-id>/tmp`。
- 发布版本目录固定，重复发布会报错；当前指针通过原子替换更新。

## 运行测试

```bash
python -m unittest discover -s tests -v
```

测试使用小数据直接得到基准结果，再以 64 字节强制小内存运行同一计划并逐行比较。
